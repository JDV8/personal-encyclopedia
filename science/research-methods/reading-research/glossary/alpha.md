# Alpha (significance level)

The threshold probability chosen before a test for rejecting the null hypothesis, conventionally 0.05. If the null hypothesis is true, a test with alpha of 0.05 will produce a false positive about 5% of the time. Alpha is the type I error rate the researcher is willing to accept, not the probability that a significant finding is wrong.
