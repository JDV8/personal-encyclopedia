# Social welfare function

A function that ranks social states according to the well-being of all individuals, used to evaluate policies. A utilitarian function adds utilities; a Rawlsian function looks at the worst-off person; others weigh in between. Abram Bergson and Paul Samuelson developed the concept. Arrow's theorem shows such a function cannot be derived from individual rankings alone without further value judgements.
