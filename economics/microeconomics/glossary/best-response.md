# Best response

The strategy that gives a player the highest payoff given the strategies chosen by the others. A best response function maps every possible choice by rivals into one's own optimal choice; in Cournot competition, for example, each firm's best output falls as its rival's output rises. A Nash equilibrium is a situation in which every player is playing a best response to everyone else.
