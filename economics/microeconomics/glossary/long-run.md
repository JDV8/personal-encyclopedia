# Long run

A period long enough that a firm can vary all its inputs, including plant size and capital, and that firms can enter or exit an industry. There is no fixed calendar length; it depends on the industry. In the long run there are no fixed costs, and competition drives economic profit to zero. Alfred Marshall introduced the distinction between short and long run.
