# Diminishing marginal returns

The tendency for each additional unit of a variable input, such as labour, to add less output than the previous one when other inputs, such as land or capital, are held fixed. It explains why short-run marginal cost eventually rises. It is a short-run concept and should not be confused with decreasing returns to scale, which concern increasing all inputs together.
