# Marginal rate of technical substitution

The rate at which a firm can replace one input with another while keeping output constant: the absolute slope of an isoquant. It equals the ratio of the inputs' marginal products. A cost-minimising firm chooses inputs so that it equals the ratio of input prices.

In this course the term is introduced in [Isoquants and input choice](../04-producer-theory/04-isoquants-and-input-choice.md), part of the section [Producer theory](../04-producer-theory/README.md).
