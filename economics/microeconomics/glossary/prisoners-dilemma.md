# Prisoners' dilemma

A game in which each player has a dominant strategy to defect, yet both would be better off if both cooperated. Formulated at RAND in 1950 by Flood and Dresher and named by Albert Tucker. It models cartels, arms races, public goods contributions and climate negotiations. Repetition, reputation and enforceable agreements can sustain cooperation.

In this course the term is introduced in [The prisoner's dilemma and cartels](../05-market-structures/12-prisoners-dilemma-and-cartels.md), part of the section [Market structures and game theory](../05-market-structures/README.md).
