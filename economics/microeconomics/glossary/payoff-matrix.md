# Payoff matrix

A table showing the payoffs to each player for every combination of strategies in a simultaneous game. Rows represent one player's strategies, columns the other's, and each cell lists both payoffs. It is the standard way to represent games such as the prisoners' dilemma.

In this course the term is introduced in [Game theory basics](../05-market-structures/10-game-theory-basics.md), part of the section [Market structures and game theory](../05-market-structures/README.md).
