# Common resource

A good that is rival but non-excludable: anyone can use it, but each use leaves less for others. Ocean fisheries, groundwater, unregulated pastures and the atmosphere's capacity to absorb carbon are examples. Because each user ignores the cost imposed on others, common resources tend to be overused, the tragedy of the commons. Property rights, quotas, fees and community governance are possible remedies.
