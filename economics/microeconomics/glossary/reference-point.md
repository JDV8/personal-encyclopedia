# Reference point

In prospect theory, the benchmark, often the status quo or an expectation, against which outcomes are evaluated as gains or losses. Changing the reference point can change choices, even if final outcomes are the same. Kőszegi and Rabin (2006) proposed that reference points are rational expectations.
