# Production function

The relationship between the quantities of inputs used and the maximum output that can be produced with given technology, for example Q = f(K, L). It summarises a firm's technological possibilities. The Cobb–Douglas form is a common example.

In this course the term is introduced in [Production functions](../04-producer-theory/02-production-functions.md), part of the section [Producer theory](../04-producer-theory/README.md). Related terms from the same lesson: [Average product](average-product.md), [Marginal product](marginal-product.md).
