# Average variable cost

Variable cost divided by output. Because fixed costs are sunk in the short run, a competitive firm should keep producing as long as price covers average variable cost, even if it does not cover average total cost. The minimum of average variable cost is therefore the shutdown point. In the brewery example of this course, minimum average variable cost is 7.5 at an output of 5.
