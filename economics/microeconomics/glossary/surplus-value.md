# Surplus value

In Marxian economics, the difference between the value workers produce and the value of their labour power, which they receive as wages. Marx argued that surplus value is the source of profit, interest and rent, and that its extraction constitutes exploitation. The concept depends on the labour theory of value, which mainstream economics rejects.
