# Numéraire

A good chosen as the unit of account, whose price is set to one, so that all other prices are expressed relative to it. Because general equilibrium determines only relative prices, one good can always serve as numéraire. Léon Walras introduced the term.

In this course the term is introduced in [General equilibrium](../08-welfare-economics/02-general-equilibrium.md), part of the section [Welfare economics](../08-welfare-economics/README.md).
