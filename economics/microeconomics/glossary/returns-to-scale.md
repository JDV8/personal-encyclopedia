# Returns to scale

How output changes when all inputs are increased in the same proportion. With constant returns, doubling inputs doubles output; with increasing returns, output more than doubles; with decreasing returns, less than doubles. Returns to scale are a long-run concept and underlie economies and diseconomies of scale.
