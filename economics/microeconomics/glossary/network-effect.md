# Network effect

A situation in which a product becomes more valuable to each user as more people use it, as with telephones, social networks, payment systems and messaging apps. Network effects create positive feedback, so markets can tip toward a single dominant platform, raising competition concerns. They can also make it hard for better newcomers to displace incumbents.
