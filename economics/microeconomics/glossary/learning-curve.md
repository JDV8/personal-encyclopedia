# Learning curve

The relationship showing that unit costs fall as cumulative output grows, because workers and firms learn from experience. In aircraft production, the labour needed per plane historically fell by a roughly constant percentage each time cumulative output doubled. Kenneth Arrow formalised learning by doing in 1962. Learning curves can give early entrants a lasting cost advantage.
