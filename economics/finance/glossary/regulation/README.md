# Regulation terms

Securities law and regulators in the US and Canada, investor protection, fraud and central banks. This folder holds 48 entries. Each is a short paragraph linking to the lesson where the term is taught.

**Prerequisites:** [Finance glossary](../README.md); the matching lessons are linked from each entry.

## Suggested reading order

There is no single path through a glossary. Look terms up as they appear in lessons, or scan the list below alphabetically before starting the matching section.
