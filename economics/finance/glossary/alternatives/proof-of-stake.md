# Proof of stake

A consensus method in which validators put up coins as collateral to add blocks, as Ethereum has done since 2022. In this course the term is explained in context in the lesson [Cryptoassets](../../03-securities/05-alternatives/04-cryptoassets.md). That lesson also covers [Smart contract](smart-contract.md), [Stablecoin](stablecoin.md), [Private key](private-key.md) and [Crypto custody](crypto-custody.md).
