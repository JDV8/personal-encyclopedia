# Net present value (NPV)

The present value of expected cash inflows minus the present value of outflows. A positive NPV means a project adds value at the chosen discount rate. In this course the term is explained in context in the lesson [Present value and discounting](../../01-foundations/05-present-value-and-discounting.md). That lesson also covers [Internal rate of return (IRR)](internal-rate-of-return.md), [Discount rate](discount-rate.md), [Discounting](discounting.md) and [Present value (PV)](present-value.md).
