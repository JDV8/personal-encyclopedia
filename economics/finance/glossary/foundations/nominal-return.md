# Nominal return

Return stated in current money terms without adjusting for inflation. Compare with [real return](real-return.md). In this course the term is explained in context in the lesson [Inflation and real returns](../../01-foundations/07-inflation-and-real-returns.md). That lesson also covers [Consumer Price Index (CPI)](cpi.md), [Hyperinflation](hyperinflation.md), [Inflation](inflation.md) and [Real return](real-return.md).
