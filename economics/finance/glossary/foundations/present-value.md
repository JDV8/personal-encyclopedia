# Present value (PV)

The value today of a future payment or stream of payments, found by [discounting](discounting.md) at an appropriate rate. Basis of nearly all valuation. In this course the term is explained in context in the lesson [Present value and discounting](../../01-foundations/05-present-value-and-discounting.md). That lesson also covers [Net present value (NPV)](net-present-value.md), [Internal rate of return (IRR)](internal-rate-of-return.md), [Discount rate](discount-rate.md) and [Discounting](discounting.md).
