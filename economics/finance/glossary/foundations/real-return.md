# Real return

Investment return after subtracting inflation: roughly nominal return minus inflation rate. It measures change in purchasing power. In this course the term is explained in context in the lesson [Inflation and real returns](../../01-foundations/07-inflation-and-real-returns.md). That lesson also covers [Nominal return](nominal-return.md), [Consumer Price Index (CPI)](cpi.md), [Hyperinflation](hyperinflation.md) and [Inflation](inflation.md).
