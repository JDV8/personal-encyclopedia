# Internal rate of return (IRR)

The discount rate that makes a project's net present value equal to zero. Useful but can mislead when cash flows change sign repeatedly. In this course the term is explained in context in the lesson [Present value and discounting](../../01-foundations/05-present-value-and-discounting.md). That lesson also covers [Discount rate](discount-rate.md), [Discounting](discounting.md), [Present value (PV)](present-value.md) and [Net present value (NPV)](net-present-value.md).
