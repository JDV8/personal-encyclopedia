# Fundamental value

The present value of the cash flows an asset is expected to produce; the benchmark against which bubbles are judged. In this course the term is explained in context in the lesson [Tulip mania](../../08-history/03-tulip-mania.md). That lesson also covers [Windhandel](windhandel.md) and [Tulip mania](tulip-mania.md).
