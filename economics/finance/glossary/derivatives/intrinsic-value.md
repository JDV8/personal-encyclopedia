# Intrinsic value

An option's payoff if exercised now: the amount by which it is in the money, never below zero. In this course the term is explained in context in the lesson [Options: calls and puts](../../03-securities/04-derivatives/03-options-calls-and-puts.md). That lesson also covers [Time value of an option](time-value-of-an-option.md), [Moneyness](moneyness.md), [Put-call parity](put-call-parity.md) and [Call option](call-option.md).
