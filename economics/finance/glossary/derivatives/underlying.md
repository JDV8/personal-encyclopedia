# Underlying

The asset, rate or index from which a derivative's value is derived. In this course the term is explained in context in the lesson [What is a derivative?](../../03-securities/04-derivatives/01-what-is-a-derivative.md). That lesson also covers [Hedging](hedging.md), [Speculation](speculation.md), [Arbitrage](arbitrage.md) and [Counterparty risk](counterparty-risk.md).
