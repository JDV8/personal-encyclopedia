# Finance glossary

Short entries for the vocabulary of the finance course: 583 terms in 13 folders. Each entry is a paragraph, not a one-line gloss; it links to the lesson where the term is taught and to neighbouring terms. Use it while reading, and treat the lessons as the place where each idea is built up.

**Prerequisites:** none; this is a lookup list. For reading order see the [finance course](../README.md).

## Suggested reading order

Read lessons first and look terms up as they appear. If you want a first pass, start with these handfuls:

1. Money and risk: [time value of money](foundations/time-value-of-money.md), [risk](foundations/risk.md), [diversification](foundations/diversification.md).
2. Securities: [share](stocks/share.md), [bond](bonds/bond.md) and [security](firms-and-accounting/security.md).
3. Canada: [TFSA](personal-investing-canada/tfsa.md), [RRSP](personal-investing-canada/rrsp.md), [FHSA](personal-investing-canada/fhsa.md).
