# Efficient frontier

The set of portfolios offering the highest expected return for each level of risk; any portfolio below it is dominated. In this course the term is explained in context in the lesson [The efficient frontier](../../06-portfolio-theory/02-the-efficient-frontier.md). That lesson also covers [Minimum-variance portfolio](minimum-variance-portfolio.md), [Tangency portfolio](tangency-portfolio.md), [Capital allocation line](capital-allocation-line.md) and [Modern portfolio theory](modern-portfolio-theory.md).
