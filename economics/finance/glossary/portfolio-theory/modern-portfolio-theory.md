# Modern portfolio theory

Harry Markowitz's 1952 framework for choosing portfolios by their expected return and variance, showing how diversification lowers risk for a given return. In this course the term is explained in context in the lesson [The efficient frontier](../../06-portfolio-theory/02-the-efficient-frontier.md). That lesson also covers [Efficient frontier](efficient-frontier.md), [Minimum-variance portfolio](minimum-variance-portfolio.md), [Tangency portfolio](tangency-portfolio.md) and [Capital allocation line](capital-allocation-line.md).
