# Benchmark

A reference index against which a portfolio's performance is measured. In this course the term is explained in context in the lesson [Measuring performance](../../06-portfolio-theory/08-measuring-performance.md). That lesson also covers [Sharpe ratio](sharpe-ratio.md), [Maximum drawdown](maximum-drawdown.md), [Geometric mean](geometric-mean.md) and [Time-weighted return](time-weighted-return.md).
