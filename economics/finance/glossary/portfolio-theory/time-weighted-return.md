# Time-weighted return

A return measure that removes the effect of cash flows in and out, used to judge managers. In this course the term is explained in context in the lesson [Measuring performance](../../06-portfolio-theory/08-measuring-performance.md). That lesson also covers [Money-weighted return](money-weighted-return.md), [VIX](vix.md), [Benchmark](benchmark.md) and [Sharpe ratio](sharpe-ratio.md).
