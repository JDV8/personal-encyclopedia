# Tangency portfolio

The risky portfolio with the highest Sharpe ratio, found where a line from the risk-free rate touches the efficient frontier. In this course the term is explained in context in the lesson [The efficient frontier](../../06-portfolio-theory/02-the-efficient-frontier.md). That lesson also covers [Capital allocation line](capital-allocation-line.md), [Modern portfolio theory](modern-portfolio-theory.md), [Efficient frontier](efficient-frontier.md) and [Minimum-variance portfolio](minimum-variance-portfolio.md).
