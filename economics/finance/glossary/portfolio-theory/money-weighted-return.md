# Money-weighted return

The internal rate of return on actual cash flows; reflects an investor's timing of contributions. In this course the term is explained in context in the lesson [Measuring performance](../../06-portfolio-theory/08-measuring-performance.md). That lesson also covers [VIX](vix.md), [Benchmark](benchmark.md), [Sharpe ratio](sharpe-ratio.md) and [Maximum drawdown](maximum-drawdown.md).
