# Minimum-variance portfolio

The portfolio on the efficient frontier with the lowest possible risk. In this course the term is explained in context in the lesson [The efficient frontier](../../06-portfolio-theory/02-the-efficient-frontier.md). That lesson also covers [Tangency portfolio](tangency-portfolio.md), [Capital allocation line](capital-allocation-line.md), [Modern portfolio theory](modern-portfolio-theory.md) and [Efficient frontier](efficient-frontier.md).
