# Prime-boost

A strategy in which a first vaccine primes the immune system and a later dose, of the same vaccine or a different one, boosts it. Heterologous prime-boost uses different platforms, for instance an adenovirus vector followed by mRNA, which sometimes gives stronger responses than repeating the same vaccine. The Ebola vaccine Zabdeno/Mvabea uses this approach.
