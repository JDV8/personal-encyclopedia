# Confidence interval

A range of values around an estimate that reflects statistical uncertainty; a 95% confidence interval would contain the true value in 95% of repeated studies if there were no bias. Wide intervals indicate imprecision. A study with an interval including 1 for a relative risk is consistent with no effect, but does not prove there is none.
