# B cell

A white blood cell of the adaptive immune system whose receptor is a membrane-bound antibody. When a B cell meets its antigen, with help from T cells, it multiplies and becomes antibody-secreting plasma cells or long-lived memory B cells. B cells are the main target of most vaccines, which aim to leave behind memory cells and protective antibody levels.
