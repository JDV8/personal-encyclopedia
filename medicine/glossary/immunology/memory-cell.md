# Memory cell

A long-lived B or T cell left after an immune response that can react faster and more strongly to the same antigen. Memory cells are the main goal of vaccination. Even when antibody levels fall, memory B and T cells can often limit severe disease, as with hepatitis B vaccine, though they may be too slow to block fast infections such as influenza.
