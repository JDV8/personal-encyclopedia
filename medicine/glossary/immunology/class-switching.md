# Class switching

The process by which a B cell changes the class of antibody it makes, for example from IgM to IgG or IgA, while keeping the same antigen specificity. It requires signals from helper T cells and happens mainly in germinal centres. Vaccines that recruit T-cell help, such as protein and conjugate vaccines, induce class-switched, long-lived responses; plain polysaccharide vaccines largely do not.
