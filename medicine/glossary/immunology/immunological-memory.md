# Immunological memory

The ability of the adaptive immune system to remember an antigen and respond faster and more strongly the next time, recorded since antiquity in the observation that survivors of plague or smallpox rarely caught it twice. It rests on memory B cells, memory T cells and long-lived plasma cells, and its duration varies greatly between diseases and vaccines.
