# Greek terms

Transliterated keywords from the Greek path — arche, logos, eudaimonia, epoché, and their neighbors. Each entry is a short paragraph with links to thinkers, texts, and concept lessons. Prefer these terms, when you can, to a looser English stand-in.

**Prerequisites:** the [glossary overview](../README.md), and the relevant tradition's introductory lesson.

## Suggested reading order

Use this list as a lookup while reading the Greek lessons and texts. A good first handful: arche, logos, arete, eudaimonia, physis, nomos, ousia, telos.
