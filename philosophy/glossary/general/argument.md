# Argument

An argument, in the logical sense, is a set of premises offered as a reason for a conclusion, not a quarrel. Validity, soundness, fallacy, deduction, and induction are tools for inspecting arguments. Ancient philosophy is full of arguments in this sense, including in texts that look like stories or sayings.
