# Thrownness

Heidegger's term (*Geworfenheit*) for the fact that Dasein finds itself already "thrown" into existence, into a particular world, body, history, language and mood it did not choose. It is part of the structure of care, together with projection (pressing into possibilities) and falling (absorption in the everyday). Sartre's "facticity" is a close relative. Thrownness sets limits within which freedom operates; authenticity does not escape it but takes it over.
