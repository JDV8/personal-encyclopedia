# Paradigm

From Greek *paradeigma*, model or example. In Thomas Kuhn's *Structure of Scientific Revolutions* (1962), the shared achievements, theories, methods and exemplary problem-solutions that define normal science for a community. A "paradigm shift" is a scientific revolution in which one paradigm is replaced by another, incommensurable one. Kuhn later distinguished the broad "disciplinary matrix" from "exemplars". The phrase "paradigm shift" is now used loosely for any big change.
