# Logic concepts

Granular lessons on argument, contradiction, the syllogism, the later Mohist canons, and the School of Names. The point is that careful inference is not a Greek exclusive, and that paradox can be serious work.

**Prerequisites:** [Philosophy](../../README.md) and the [concepts overview](../README.md).
