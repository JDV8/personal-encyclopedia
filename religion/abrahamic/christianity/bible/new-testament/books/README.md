# New Testament books

This folder is the book-by-book path through all twenty-seven New Testament writings, grouped in the usual Christian order: [Gospels](gospels/README.md), [history](history/README.md) (Acts), [Pauline epistles](pauline-epistles/README.md), [general epistles](general-epistles/README.md), and [prophecy](prophecy/README.md) (Revelation). Each book has its own overview: name, authorship (traditional and scholarly), context, outline, key passages, themes, and reception. The [survey lessons](../../README.md) and the [story lessons](../../stories/README.md) retell the main narrative; these files study each writing as a writing.

## Suggested reading order

Read the [foundation and survey lessons](../../README.md) first, then either follow the story path and use these overviews as companions, or read section by section starting with the [Gospels](gospels/README.md). Within each section, file order is canonical order. [Hebrews](general-epistles/hebrews.md) is placed with the general epistles, with a note on its traditional position after [Philemon](pauline-epistles/philemon.md).

## References & further reading

- Raymond E. Brown, *An Introduction to the New Testament* (Intermediate). The standard full introduction to every book in this folder.
- Bart D. Ehrman, *The New Testament: A Historical Introduction to the Early Christian Writings* (Beginner). A clear critical survey, to be read alongside more traditional treatments.
- Luke Timothy Johnson, *The Writings of the New Testament* (Intermediate). A historically serious introduction with more sympathy for traditional authorship claims than Ehrman.
