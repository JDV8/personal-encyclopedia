# Terms

Words and institutions a reader keeps meeting: canon, covenant language, parties, rites, titles, and later scholarly names (such as "messianic secret"). Each entry is a paragraph with links, not a complete treatise; the [themes](../themes/README.md) take a few ideas at more length.

## Suggested reading order

Start with: [Canon](canon.md), [Torah](torah.md), [Pharisees](pharisees.md), [Gospel](gospel.md), [Faith](faith.md), [YHWH](yhwh.md). Then read the rest as needed, or follow links from the book overviews and lessons.
