# People

Named figures of the biblical library: ancestors, kings, prophets, and the men and women of the Gospels and letters. Each entry is a short portrait with links to the book overviews and story lessons. It is not a substitute for reading the narratives.

## Suggested reading order

Start with: [Abraham](abraham.md), [Moses](moses.md), [David](david.md), [Isaiah](isaiah.md), [Jesus](jesus.md), [Mary](mary.md), [Peter](peter.md), [Paul](paul.md). Then read the rest as needed, or follow links from the book overviews and lessons.
