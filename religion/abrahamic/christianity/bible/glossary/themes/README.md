# Themes

Longer thematic files on ideas that run across many books: covenant, Messiah, temple, exile and return, the kingdom of God, sacrifice and atonement, prophecy, Israel and the nations, and the later pairing of law and gospel. Read these after some of the narrative path, not instead of it.

## Suggested reading order

Start with: [Covenant](covenant.md), [Messiah](messiah.md), [Temple](temple.md), [Exile and return](exile-and-return.md), [Kingdom of God](kingdom-of-god.md). Then read the rest as needed, or follow links from the book overviews and lessons.
