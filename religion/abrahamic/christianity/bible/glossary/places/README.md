# Places

Places that carry meaning in the biblical story: lands, cities, mountains, and the later urban stages of the early church. Geography here is almost always theological as well as physical.

## Suggested reading order

Start with: [Jerusalem](jerusalem.md), [Sinai](sinai.md), [Babylon](babylon.md), [Rome](rome.md), [Galilee](galilee.md). Then read the rest as needed, or follow links from the book overviews and lessons.
